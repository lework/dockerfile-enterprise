# 实践篇：准备工作

欢迎来到 Dockerfile 中小企业实战的实践篇！在接下来的章节中，我们将一起动手构建各种实用的 Docker 镜像，从基础的操作系统环境到常见的开发语言应用，再到 CI/CD 流程中的镜像使用。

**本篇目标：**

为了尽可能模拟真实的中小企业环境，我们后续会搭建一些常用的内部服务（如代码仓库、镜像仓库、代理仓库等）。本准备篇旨在帮助你搭建一个合适的基础环境，以便顺利跟进后续的所有实战操作。

**选择适合你的准备路径：**

我们提供两种环境准备路径，请根据你的情况选择：

1.  **本地学习环境 (推荐给初学者):** 使用你自己的电脑（Windows, macOS 或 Linux），安装 Docker Desktop 或 Docker Engine。这是最快、最简单的入门方式。
2.  **模拟企业环境 (可选/进阶):** 使用一台 Linux 服务器，并配置内网域名和 Nginx 反向代理。这更贴近真实的企业部署场景，但相对复杂。

---

## 路径一：本地学习环境 (推荐)

这是最推荐的方式，尤其是如果你是 Docker 新手或者只想专注于学习 Dockerfile 本身。

**你需要：**

1.  **安装 Docker:**
    - **Windows / macOS 用户:** 下载并安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)。它包含了 Docker Engine、Docker CLI 客户端以及图形化界面。
    - **Linux 用户:** 根据你的发行版，参考 Docker 官方文档安装 [Docker Engine](https://docs.docker.com/engine/install/)。例如，对于 Debian/Ubuntu，可以参考路径二中的安装步骤，但可以跳过复杂的 `daemon.json` 配置。
2.  **安装 Git:** 用于后续从代码仓库拉取示例代码。访问 [Git 官网](https://git-scm.com/downloads) 下载并安装。
3.  **(可选) 安装代码编辑器:** 一个好的代码编辑器（如 [Visual Studio Code](https://code.visualstudio.com/)）会让编写 Dockerfile 和代码更方便。

**后续访问方式：**

在这种模式下，后续章节中我们搭建的各种服务（如 Gitlab, Harbor, Jenkins）通常会通过 `localhost:<端口号>` 或 `127.0.0.1:<端口号>` 来访问。

---

## 路径二：模拟企业环境 (可选/进阶)

如果你想体验更完整的、类似企业内部的部署流程，可以选择此路径。这需要你对 Linux 和网络有一定基础。

**你需要：**

1.  **一台 Linux 服务器:**

    - **推荐系统:** Debian 11 或 Ubuntu 20.04 LTS / 22.04 LTS。
    - **建议配置:** 至少 2 核 CPU，4GB 内存，40GB 硬盘空间（用于存放 Docker 镜像和数据）。当然，配置越高越好。
    - **权限:** 需要有 `sudo` 或 `root` 权限。

2.  **规划内网域名 (可选但推荐):**
    为了模拟通过域名访问内部服务，你可以规划一些内部域名，并在服务器和你的**本地访问机器**上配置 `/etc/hosts` (Linux/Mac) 或 `C:\Windows\System32\drivers\etc\hosts` (Windows) 文件，将这些域名指向你的 Linux 服务器 IP 地址（假设为 `192.168.77.140`）。

    **示例域名规划：**

    - `git.leops.local` (代码仓库，如 Gitlab)
    - `harbor.leops.local` (镜像仓库，如 Harbor)
    - `jenkins.leops.local` (CI/CD 工具，如 Jenkins)
    - `nexus.leops.local` (代理仓库，如 Nexus)
    - `verdaccio.leops.local` (NPM 代理)
    - `goproxy.leops.local` (Go 代理)
    - `transfer.leops.local` (文件传输)

    **示例 hosts 文件配置 (添加到服务器和你本地电脑):**

    ```
    192.168.77.140 git.leops.local
    192.168.77.140 harbor.leops.local
    192.168.77.140 jenkins.leops.local
    192.168.77.140 nexus.leops.local
    192.168.77.140 npm.leops.local
    192.168.77.140 goproxy.leops.local
    192.168.77.140 transfer.leops.local
    ```

    _后续我们将使用 Nginx 统一处理这些域名的流量转发。_

3.  **在 Linux 服务器上安装 Docker Engine:**
    以下是在 Debian/Ubuntu 系统上安装 Docker 的推荐步骤（使用国内镜像源加速）：

    ```bash
    # 1. 更新包列表并安装必要工具
    sed -i -e 's#deb.debian.org#mirrors.aliyun.com#g' \
           -e 's#security.debian.org#mirrors.aliyun.com#g' \
           -e 's#ftp.debian.org#mirrors.aliyun.com#g' \
           /etc/apt/sources.list
    sudo apt-get update
    sudo apt-get install -y ca-certificates curl gnupg lsb-release bash-completion

    # 2. 添加 Docker 官方 GPG 密钥 (使用阿里云镜像)
    wget -qO - http://mirrors.aliyun.com/docker-ce/linux/debian/gpg | sudo apt-key add -

    # 3. 设置 Docker 的 APT 仓库 (使用阿里云镜像)
    echo "deb [trusted=yes] http://mirrors.aliyun.com/docker-ce/linux/debian $(lsb_release -cs) stable" > /etc/apt/sources.list.d/docker-ce.list

    # 4. 安装 Docker Engine
    sudo apt-get update
    sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

    # 5. 配置 Docker Daemon (创建或修改 /etc/docker/daemon.json)
    sudo mkdir -p /etc/docker
    sudo tee /etc/docker/daemon.json > /dev/null <<EOF
    {
      "registry-mirrors": [
          "https://docker.1panel.dev",
          "https://docker.fxxk.dedyn.io",
          "https://docker.xn--6oq72ry9d5zx.cn",
          "https://docker.llkk.cc",
          "https://a.ussh.net",
          "https://docker.zhai.cm"
      ],
      "log-driver": "json-file",
      "log-opts": {
        "max-size": "200m",
        "max-file": "3"
      },
      "live-restore": true
    }
    EOF
    # 说明:
    # registry-mirrors: 配置国内镜像加速器，拉取官方镜像更快。
    # log-driver/log-opts: 配置日志轮转，防止日志文件过大。
    # live-restore: 允许在 Docker 守护进程升级或重启时，保持运行中的容器继续运行。

    # 6. 重启 Docker 服务使配置生效
    sudo systemctl restart docker && sudo systemctl enable docker
    ```

4.  **安装 Git:**

    ```bash
    sudo apt-get update
    sudo apt-get install -y git
    ```

5.  **准备 Nginx 作为反向代理:**
    我们将使用 Nginx 来接收所有 HTTP/HTTPS 请求（通过上面配置的域名），并将请求转发给后端运行在 Docker 容器中的各个服务（Gitlab, Harbor 等）。这样可以统一管理入口，方便后续配置 HTTPS。

    - **创建 Nginx 数据和配置目录:**

      ```bash
      mkdir -p /data/nginx/nginx_data/conf
      mkdir -p /data/nginx/nginx_data/logs
      mkdir -p /data/nginx/nginx_data/conf.d # 用于存放各个服务的代理配置
      ```

    - **准备基础 Nginx 配置文件 (`/data/nginx/nginx_data/conf/nginx.conf`):**

      ```nginx
      user nginx;
      worker_processes auto;
      pid /var/run/nginx.pid;
      include /etc/nginx/modules-enabled/*.conf;

      events {
          worker_connections 10240;
          multi_accept on;
          use epoll;
      }

      http {
          sendfile on;
          tcp_nopush on;
          tcp_nodelay on;
          keepalive_timeout 65;
          keepalive_requests 10240;

          client_max_body_size 1024m;
          client_body_buffer_size 128k;
          types_hash_max_size 2048;

          include /etc/nginx/mime.types;
          default_type application/octet-stream;

          ssl_protocols TLSv1.2 TLSv1.3;
          ssl_prefer_server_ciphers on;

          access_log /var/log/nginx/access.log;
          error_log /var/log/nginx/error.log;

          gzip on;

          # 包含 conf.d 目录下的所有 .conf 文件
          include /etc/nginx/conf.d/*.conf;
      }
      ```

      _你可以将上面的内容保存到 `/data/nginx/nginx_data/conf/nginx.conf` 文件中。_

    - **准备一个代理示例 (`/data/nginx/nginx_data/conf.d/default.conf`):**
      这个文件只是一个占位符或默认配置，后续我们会为 `git.leops.local`, `harbor.leops.local` 等创建专门的配置文件。

      ```nginx
      server {
          listen 80 default_server;
          listen [::]:80 default_server;
          server_name _;

          location / {
              root /usr/share/nginx/html;
              index index.html index.htm;
          }

          location /healthz {
              access_log off;
              return 200 "healthy";
              add_header Content-Type text/plain;
          }
      }
      ```

      _将这个内容保存到 `/data/nginx/nginx_data/conf.d/default.conf`。_

    - **使用 Docker Compose 运行 Nginx:**
      在 `/data/nginx/` 目录下创建一个 `docker-compose.yml` 文件：

      ```yaml
      services:
        nginx:
          container_name: nginx-proxy
          image: nginx:1.27-alpine
          restart: always
          ports:
            - '80:80'
            - '443:443'
          volumes:
            - /data/nginx/nginx_data/conf/nginx.conf:/etc/nginx/nginx.conf:ro
            - /data/nginx/nginx_data/conf.d:/etc/nginx/conf.d:ro
            - /data/nginx/nginx_data/logs:/var/log/nginx:rw
            # (可选) 如果需要配置 HTTPS，挂载证书目录
            # - /data/nginx/nginx_data/certs:/etc/nginx/certs:ro
          healthcheck:
            test: wget --quiet --tries=1 --spider http://localhost/healthz || exit 1
            interval: 30s
            timeout: 5s
            retries: 3
      ```

      然后在该文件所在目录运行 `docker compose up -d` 启动 Nginx 容器。

**统一要求 (无论选择哪个路径):**

- **Docker 环境:** 确保你的 Docker Engine 或 Docker Desktop 正在运行。
- **Git 客户端:** 确保你已经安装了 Git。

准备好以上环境后，你就可以顺利地开始我们的 Dockerfile 实战之旅了！
