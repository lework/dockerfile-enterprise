# Docker 镜像代理加速器配置指南

配置的是执行 `docker pull` 的 Docker Engine，`registry-mirrors` 用于加速 Docker Hub 镜像。准备一个部署方认可的 HTTPS 镜像源，替换下面的示例地址。私有仓库仍使用自身的地址和认证配置。[Docker Hub 镜像加速配置](https://docs.docker.com/docker-hub/image-library/mirror/)

```json
{
  "registry-mirrors": ["https://mirror.example.com"]
}
```

## Linux 上的 Docker Engine

如果 `/etc/docker` 目录不存在，先运行 `sudo mkdir -p /etc/docker`。备份已有的 `daemon.json`，用 `sudoedit /etc/docker/daemon.json` 在原 JSON 对象中添加或更新 `registry-mirrors`，保留其他键值。

在使用 systemd 的主机上运行以下命令。通过语法检查后，才会重载 Docker 服务。

```bash
sudo dockerd --validate --config-file=/etc/docker/daemon.json &&
  sudo systemctl reload docker
```

## Docker Desktop

在 macOS 或 Windows 上打开 Docker Desktop 的 **Settings → Docker Engine**，复制原配置作为备份。合并 `registry-mirrors` 后，点击 **Apply & Restart**。

## 验证与回退

```bash
docker info --format '{{json .RegistryConfig.Mirrors}}'
docker pull docker.io/library/alpine:3.22
```

`docker info` 输出中应包含刚配置的地址。`docker pull` 用于验证镜像可以拉取，若要确认请求实际到过镜像源，再查镜像源访问日志。

撤销时恢复备份。首次配置且没有备份时，删除新增的 `registry-mirrors`。按系统对应的步骤重新应用配置，再用 `docker info` 回读。
